# Retail Customer Segmentation & High-Value Customer Prediction

## Project Overview

This project analyzes customer demographics, website activity, purchasing behavior, and campaign responses to identify customer segments and predict `HighValueCustomer` status.

## Key Work

- Performed data exploration, missing-value treatment, and categorical encoding.
- Conducted Exploratory Data Analysis (EDA) using distributions, scatter plots, correlation analysis, and outlier detection.
- Applied **K-Means clustering** to identify customer segments and evaluated clustering quality using the silhouette score.
- Compared clustering results with **Agglomerative Clustering**.
- Used **PCA and t-SNE** for dimensionality reduction and visualization.
- Built **Logistic Regression, KNN, and Random Forest** classification models.
- Evaluated models using Accuracy, Precision, Recall, F1-score, and confusion matrices.
- Identified `PurchaseAmount` and `PreviousPurchases` as important indicators associated with high-value customers.
- Translated analytical findings into practical strategies for customer retention, upselling, cross-selling, and reactivation.

## Tools & Technologies

- **Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn
- **Environment:** Jupyter Notebook / Google Colab
- **Techniques:** EDA, Customer Segmentation, K-Means, Agglomerative Clustering, PCA, t-SNE, Classification, Predictive Analytics

## Business Outcome

The analysis provides a framework for differentiating customer groups based on engagement, purchasing behavior, and loyalty, enabling more targeted marketing campaigns and customer-value strategies.
